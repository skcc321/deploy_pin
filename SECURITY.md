# Security Policy

## Supported Versions

Security fixes are released for the latest minor version.

| Version | Supported          |
| ------- | ------------------ |
| 1.8.x   | :white_check_mark: |
| < 1.8   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/skcc321/deploy_pin/security/advisories/new).

I will take a look as soon as possible and publish the advisory once a fix is released.
